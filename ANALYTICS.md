# Карта событий Яндекс.Метрики

Транспорт: `src/analytics/metrika.ts` (`goal(name, params)` → `ym(ID, 'reachGoal', …)`).
Обертки событий: `src/analytics/events.ts`. ID счётчика: `VITE_YM_ID` в `.env` (без него всё no-op).

Правила для правок:
- Параметры цели — плоский объект, значения только `string | number | boolean` (вложенность Метрика не принимает).
- Не отправлять персональные данные и имена файлов пользователя (название трека — это имя файла; при желании заменить на хеш).
- Имена целей — строчные, через подчёркивание; они же видны в отчёте «Конверсии».

## События

| Цель | Где вызывается | Когда срабатывает |
|---|---|---|
| `app_open` | `src/main.ts` → `evAppOpen()` | Один раз при загрузке страницы |
| `level_start` | `src/core/Game.ts` → `Game.play()` | Старт песни; в хардкоре каждая попытка — отдельное событие |
| `level_complete` | `src/scenes/PlayScene.ts` → `finish()` | Песня доиграна до конца |
| `new_record` | `src/scenes/PlayScene.ts` → `finish()` | Финиш с новым рекордом (не в практике) |
| `death` | `src/scenes/PlayScene.ts` → `onDeath()` | Смерть (откат к чекпоинту или рестарт) |
| `level_quit` | `src/scenes/PlayScene.ts` → `quit()` | Выход в меню из паузы посреди песни |
| `track_upload` | `src/core/Game.ts` → `Game.addFile()` | Игрок добавил свой аудиофайл (пикер или drag & drop) |

## Параметры

### `app_open`
| Параметр | Тип | Описание |
|---|---|---|
| `screen` | string | Размер окна, напр. `1920x1080` |
| `dpr` | number | devicePixelRatio |
| `touch` | boolean | Сенсорный ввод доступен |

Отдельно уходят параметры посетителя (`userParams`, отчёт «Параметры посетителей»): `touch`, `lang`.

### Общие параметры уровня (все события уровня)
| Параметр | Тип | Описание |
|---|---|---|
| `track` | string | Название трека |
| `artist` | string? | Исполнитель (может отсутствовать) |
| `custom` | boolean | Трек загружен игроком, а не из плейлиста |
| `mode` | string | `Чекпоинты` / `Хардкор` |
| `difficulty` | string | `Лёгкий` / `Нормальный` / `Сложный` |

### `level_start`
| Параметр | Тип | Описание |
|---|---|---|
| `attempt` | number | Номер попытки (1 — свежий старт; в хардкоре растёт) |

### `level_complete`
| Параметр | Тип | Описание |
|---|---|---|
| `score` | number | Очки |
| `rank` | string | `S` / `A` / `B` / `C` / `D` |
| `acc_pct` | number | Точность, % (один знак после запятой) |
| `max_combo` | number | Максимальное комбо |
| `deaths` | number | Смертей за прохождение |
| `attempts` | number | Номер попытки, на которой пройдено (хардкор) |
| `practice` | boolean | Практика хардкора (рекорд не сохраняется) |
| `duration_s` | number | Длительность трека, сек |

### `new_record`
| Параметр | Тип | Описание |
|---|---|---|
| `score` | number | Очки рекордного прохождения |

### `death`, `level_quit`
| Параметр | Тип | Описание |
|---|---|---|
| `progress_pct` | number | Прогресс по треку, % (0–100) |

### `track_upload`
| Параметр | Тип | Описание |
|---|---|---|
| `ext` | string | Расширение файла (`mp3`, `flac`, …) |
| `size_mb` | number | Размер файла, МБ (один знак после запятой) |

## Как добавить событие

1. Новая обертка `evЧтоТо(...)` в `src/analytics/events.ts`, внутри — `goal('имя_цели', { ... })`.
2. Вызов в нужном месте кода (сцена / `Game`).
3. Строка в таблицы выше.
4. Проверка: `npm run build`, затем в кабинете Метрики — «Конверсии» (события появляются с задержкой до ~15 минут).

## Кандидаты на добавление (не реализовано)

- `level_abandon_load` — файл выбран, но уровень не построился (ошибка декодирования аудио).
- `first_input_ms` — время от старта песни до первого нажатия.
- `menu_nav` — навигация по меню/настройкам.
- `session_songs` — сколько песен сыграно за сессию (счётчик на клиенте, слать при уходе со страницы).
