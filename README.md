# ПРЫГ! — ритм-раннер на одной кнопке

Браузерная игра, в которой уровень **строится под музыку**. Игра сама слушает трек:
находит темп и биты, бочку, громкие и тихие части, дропы. Из этого собирается трасса,
где каждый прыжок приходится точно в бит, а приземление — на следующий.

- Управление — **одна кнопка: ПРОБЕЛ** (или клик/тап по экрану)
- Треки из папки `playlist/` — это основные уровни игры
- Можно загрузить **свой MP3** кнопкой «Свой трек» или просто перетащить файл в окно
- Два режима:
  - **Поток** (попроще): ошибка не останавливает музыку, звук на секунду «глохнет», и бежишь дальше
  - **Хардкор**: одна ошибка — и трек начинается **с самого начала**. Считаются попытки и лучший процент
    прохождения, как в Geometry Dash. Уровни здесь заметно злее: прыжки на каждой доле, длинные цепочки
    колец, розовые кольца между долями, шипастые потолки, которые наказывают лишний прыжок, широкие шипы,
    узкие края пропастей, выше скорость и меньше прощения по таймингу
- Три сложности в каждом режиме: Лёгкий / Нормальный / Сложный
- Оценка каждого прыжка: PERFECT / GREAT / GOOD / MISS, комбо, ранги S–D, рекорды

Чтобы музыку было видно, а не только слышно:
- город на фоне — это эквалайзер, высоту домов задаёт спектр трека;
- солнце и камера качаются в такт бочке;
- линии бита на полу загораются в момент удара;
- перед каждым нужным нажатием сжимается кольцо: жми, когда оно схлопнется;
- на дропах — вспышка и прыжковая площадка, которая подбрасывает высоко без нажатия.

## Препятствия

| Что | Что делать |
| --- | --- |
| Стрелка на полу с кольцом | прыгнуть, когда кольцо сожмётся |
| Шипы | перепрыгнуть |
| Пропасть | перепрыгнуть, приземлишься ровно на следующую долю |
| Ступенька вверх | запрыгнуть |
| Кольца над пропастью | жать на каждом кольце — прыжок в воздухе |
| Розовое кольцо на вершине прыжка (хардкор) | жать между долями, в слабую долю |
| Шипастый потолок (хардкор) | **не** прыгать — проскочить можно только бегом |
| Площадка со стрелками | ничего, она сама подбросит |
| Кристаллы | собираются сами, если бежать в ритме |

## Управление

| Клавиша | Действие |
| --- | --- |
| Пробел / клик / тап | прыжок |
| Esc или P | пауза |
| M | звук вкл/выкл |
| ⚙ в меню или пауза | громкость: общая, музыка, эффекты (сохраняется в браузере) |
| ↑ ↓ в меню | выбор трека |
| ← → в меню | сложность |
| O в меню | открыть свой файл |
| Tab в меню | переключить режим Поток / Хардкор |

## Как добавить трек в основной плейлист

Положи аудиофайл (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`) в папку `playlist/`.
Имя файла лучше давать в формате `Название - Исполнитель.mp3`: тогда в меню всё подпишется правильно.
Порядок задаётся числом в начале имени: `01 Название - Исполнитель.mp3` (число в меню не показывается).

Больше ничего делать не нужно: игра сама найдёт файл при сборке и построит под него уровень.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org/) 20.19+ (лучше 22 LTS).

```bash
npm install
```

```bash
npm run dev
```

Открой адрес из терминала (обычно http://localhost:5173/).
Если добавить `?autoplay` в конец адреса, игра пройдёт трек сама: удобно, чтобы посмотреть уровень.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub.
2. В папке проекта:
   ```bash
   git init
   git add .
   git commit -m "ПРЫГ! ритм-раннер"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/ИМЯ_РЕПО.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Source: GitHub Actions**.
4. Во вкладке **Actions** дождись зелёной галочки. Игра будет по адресу
   `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/`.

> ⚠️ Всё, что лежит в `playlist/`, попадёт на публичный сайт, и любой сможет скачать эти файлы.
> Публикуй только музыку, на которую у тебя есть права: свою, с разрешения автора
> или под свободной лицензией. Чужие треки можно оставить только у себя локально
> (добавь `playlist/` в `.gitignore`), а игроки всё равно смогут загружать свои MP3.

## Как это устроено

```
src/
  audio/analyze.ts   анализ трека: спектральный поток → темп → трекинг битов → признаки каждой доли
  audio/engine.ts    воспроизведение, точные «часы» песни, живой спектр для визуала, звуки
  rhythm/chart.ts    генератор уровня: решает, где прыжок, шипы, пропасть, кольца, площадка
  rhythm/run.ts      бег и физика, привязанные ко времени песни; оценка попаданий
  game/render.ts     неоновая графика, реагирующая на музыку
  game/game.ts       меню, загрузка, HUD, пауза, результаты
  playlist.ts        автоматически собирает треки из папки playlist/
```

Генератор гарантирует проходимость: при идеальных нажатиях любой трек проходится без промахов в обоих режимах.
Для проверки треки прогонялись симуляцией со случайной неточностью нажатий. В «Потоке» на нормальной
сложности даже при ошибке ±50 мс промахов меньше 1%. В «Хардкоре» при точности ±20 мс трек проходится,
а при ±35 мс на нормальной сложности до конца доходит лишь примерно каждый третий забег.
Сложность меняет плотность препятствий и длину цепочек колец, а сила музыки в каждый момент
определяет, где будут действия, а где можно просто бежать и собирать кристаллы.
