# ПРЫГ! — платформер на одной кнопке

Браузерный платформер, в котором всё управление — **одна кнопка: ПРОБЕЛ** (или клик/тап по экрану).
Герой бежит сам, ты решаешь только, когда и насколько высоко прыгнуть.

- 10 уровней в четырёх мирах: Зелёные холмы → Кристальные пещеры → Небесные руины → Вулканическая крепость
- Механики: рушащиеся блоки, платформы сквозного прохода, движущиеся платформы и лифты,
  пружины, прыжки от стен, пилы, красные/синие блоки (переключаются каждым прыжком),
  жёлтые кольца для прыжка в воздухе, порталы переворота гравитации
- Босс на 10-м уровне (и на каждом следующем 10-м, если добавлять уровни)
- Кристаллы для сбора, чекпоинты, рекорды времени (сохраняются в браузере)
- Вся графика и звук генерируются кодом — никаких файлов-ассетов

## Управление

| Клавиша | Действие |
| --- | --- |
| Пробел / клик / тап | прыжок (держи дольше — прыгнешь выше) |
| Esc или P | пауза |
| M | звук вкл/выкл |

В меню можно пользоваться мышью или стрелками + пробел.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org/) 20.19+ (лучше 22 LTS).

```bash
npm install
```

```bash
npm run dev
```

Открой адрес, который покажет терминал (обычно http://localhost:5173/).

Сборка готового сайта в папку `dist/`:

```bash
npm run build
```

## Как выложить на GitHub Pages

1. Создай пустой репозиторий на GitHub.
2. В папке проекта:
   ```bash
   git init
   git add .
   git commit -m "Первая версия игры"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/ИМЯ_РЕПО.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Через минуту-две во вкладке **Actions** завершится сборка, и игра будет доступна по адресу
   `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/`.

Каждый следующий `git push` в `main` автоматически пересобирает и обновляет игру
(workflow лежит в `.github/workflows/deploy.yml`).

## Как добавить новый уровень

Уровни лежат в `src/levels/`. Каждый уровень — это набор ASCII-секций, которые склеиваются слева направо
(и выравниваются по нижнему краю). Пример:

```ts
import type { LevelDef } from '../engine/types.ts';

export const level11: LevelDef = {
  name: 'Новый уровень',
  theme: 'meadow', // meadow | caves | ruins | volcano
  hint: 'Подсказка, которая появится в начале',
  sections: [
    [
      '..........*..........',
      '.....................',
      '..P.......^.....E....',
      '#####################',
      '#####################',
    ],
  ],
};
```

Затем добавь его в конец списка в `src/levels/index.ts`.

### Легенда символов

| Символ | Что это |
| --- | --- |
| `#` | земля |
| `%` | каменный блок |
| `-` | платформа, сквозь которую можно запрыгнуть снизу |
| `C` | рушащийся блок |
| `R` / `U` | красный / синий блок (каждый прыжок меняет, какой из них твёрдый; в начале твёрдый красный) |
| `^` / `v` | шипы на полу / на потолке |
| `S` | пружина |
| `O` | кольцо для прыжка в воздухе |
| `G` | портал гравитации |
| `*` | кристалл |
| `F` | чекпоинт |
| `P` | старт игрока |
| `E` | выход |
| `===~~~` | горизонтальная движущаяся платформа (`=`) и её путь (`~`) |
| `HHH` + `\|` | вертикальный лифт (`H`) и его путь (`\|` в столбце первой `H`) |
| `X` + `:` | пила (`X`) и её путь (`:` по горизонтали или вертикали) |
| `B`, `T`, `D` | босс: его «дом», линия старта боя и дверь арены |

Уровень с боссом — это уровень с полем `boss` (см. `src/levels/level10.ts`): там же настраиваются
здоровье, скорость, длительность оглушения, скорость волн и количество шипастых шаров.

### Подсказки по физике

- Обычный прыжок: до ~3.5 блока вверх, через пропасть до 4 блоков (5 — очень сложно)
- Пружина подбрасывает примерно на 10 блоков
- Игрок не может остановиться: если на пути движущаяся платформа или пила,
  делай так, чтобы их можно было пройти в любой фазе движения

### Проверка уровней

В проекте есть солвер, который сам ищет прохождение уровня, нажимая только пробел,
и печатает время идеального прохождения:

```bash
npm run solve -- 11
```

А `node scripts/boss-test.ts 20` проверяет, что босса на 20-м уровне можно победить.

## Структура проекта

```
src/
  engine/     физика и логика (без графики): уровень, симуляция, босс
  game/       графика, звук, меню, сохранения
  levels/     уровни
scripts/      солвер и тест босса
```
